## Правила прогрессии — блок B (дни 11–20)

- **Длина текста: 50–80 слов** (считать по `text.split(/\s+/)`).
- **Активно используем:** `ser` vs `estar` контрастно, `hay` для
  существования, прилагательные с согласованием, возвратные глаголы
  (`levantarse`, `llamarse`, `acostarse`, `ducharse`, `vestirse`).
- **Времена:** только **Presente de Indicativo** (включая `ser`/`estar`).
- **Запрещено:** `Pretérito Perfecto/Indefinido/Imperfecto`, `Futuro`,
  `Condicional`, `Subjuntivo`, `Imperativo`, `ir a + infinitivo`.
- **Vocabulary: 8–12 записей** на текст. Только новые/трудные/типично-
  кастильские слова. Не повторять то, что уже было в a1-001 … a1-011.
- **questions: ровно 3** с тремя вариантами, проверяющими понимание.
- **grammar_notes: 1–3** записи, привязанные к конструкциям из текста.
  В этом блоке ожидаются заметки про `ser/estar`, `hay`, возвратные.

## Правила контента (для всех батчей A1)

- **Кастильский испанский.** Используем `vosotros` (если по контексту),
  `móvil`, `ordenador`, `zumo`, `coche`, `gafas`, `patata`, `mi mujer/mi marido`.
  Избегаем `coger` на A1 (давать `tomar`, `comprar`, `subir a` по смыслу).
- **Диакритика обязательна.** `á é í ó ú ñ ü ¿ ¡` — буква в букву.
- **Тексты живые:** маленькая сценка, конкретное место (Sevilla, Madrid,
  Salamanca, Valencia), именованные персонажи. Можно протягивать
  Carlos / Marta / Sofía из предыдущих текстов.
- **vocabulary[].word** для существительных — с артиклем.
- **vocabulary[].example** — фраза из текста или близкая к нему.
