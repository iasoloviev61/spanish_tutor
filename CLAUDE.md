# Spanish Learning App — гид для Claude Code

Личный учебно-тренировочный проект по испанскому. Три страницы, один стиль:
тренажёр спряжений → конспект правил → интерактивный учебник.

## Запуск

Это статический сайт без сборки. Открывайте `app/index.html` напрямую
или поднимайте локальный сервер из каталога `app/`:

```bash
cd app && python3 -m http.server 8000
```

Затем `http://localhost:8000/`. Сервер нужен только если начнут мешать ограничения
`file://` (например, для `fetch()` в будущем — сейчас всё на `<script src="...">`).

## Структура

```
spanish/
  CLAUDE.md                       # этот файл
  .claude/settings.local.json     # разрешения для Claude Code
  gramatica del uso del espanol.pdf  # сканированный учебник-источник (291 стр., 128 MB)
  app/
    index.html       # главная-хаб с тремя плитками (Тренажёр / Учебник / Конспект)
    trainer.html     # тренажёр спряжений
    notes.html       # конспект (правила чтения, ударения, фразы)
    textbook.html    # хаб учебника со списком модулей
    textbook/
      u01.html       # Unidad 1 — род существительных-людей
      u02..u05.html  # (к реализации)
    css/
      base.css       # палитра, шрифты, общий каркас (.app, header, page-nav)
      trainer.css    # стили карточек тренажёра
      notes.css      # стили конспекта
      textbook.css   # стили учебника + профильный UI
    js/
      db.js          # IndexedDB-обёртка (users / progress / settings) + JSON export/import
      profile.js     # профили: создание, переключение, опциональный PIN, UI шапки
      textbook.js    # рендер теории и интерактивных упражнений
      trainer.js     # логика тренажёра спряжений
    data/
      verbs.js              # window.VERBS = []
      verbs/<inf>.js        # один JS на глагол, push в VERBS
      textbook/u<NN>.js     # один JS на модуль, window.TEXTBOOK[id] = {...}
    PROMPT.md        # готовый промпт для генерации новых глаголов
    spanish-trainer_6.html  # legacy-снимок прежнего прототипа, не трогать
```

## Конвенции

- **Стек:** ванильный HTML / CSS / JS, без сборки и без зависимостей.
  ES2020-фичи допустимы (поддерживаются всеми современными браузерами).
- **Глобальный неймспейс:** `window.App = { db, profile, textbook }`.
  Скрипты подключаются обычными `<script src="...">`, не модули — так удобно
  держать legacy-страницы и новые в одной системе.
- **Палитра и шрифты:** определены CSS-переменными в `css/base.css`.
  Любые новые стили должны брать `var(--accent)`, `var(--ink)`, `var(--bg-card)`
  и т.д., чтобы три страницы смотрелись как одно семейство.
- **Шрифты:** `Cormorant Garamond` для заголовков и испанских акцентов,
  `Lora` для основного текста, `JetBrains Mono` для форм и кода.

## Хранение данных

**Первичное хранилище — IndexedDB** (`spanish-app`, версия 1, см. `js/db.js`).
Три objectStore:

| Store    | keyPath          | Индексы                          |
| -------- | ---------------- | -------------------------------- |
| users    | id (auto)        | name (unique)                    |
| progress | id (auto)        | userId; userUnit; userUnitEx     |
| settings | [userId, key]    | —                                |

Активный пользователь — pointer в `localStorage` под ключом
`spanish_app_active_user_v1`.

**Бэкап — экспорт JSON** через шапку (Профиль → Экспорт / импорт).
Это и есть «несгораемая» копия: положите файл в облако / в отдельную папку /
в git — и прогресс перенесётся между браузерами и устройствами.

**Тренажёр** (legacy `js/trainer.js`) пишет в `localStorage` под ключом
`spanish_trainer_v1:<userId>` — у каждого профиля своя статистика карточек.
Переход на IndexedDB опционален, но не требуется.

## Профили

Базовая, без серверной аутентификации. На странице `js/profile.js`:
- Создание профиля = имя + аватар-эмоджи + опциональный PIN (хеш SHA-256, без соли).
- Переключение в один клик; для PIN-профилей — `prompt()`.
- Шапка с переключателем монтируется в `#profile-bar` на каждой странице.
- PIN снимается / меняется в «Управление профилями».

Если профилей нет, шапка показывает приглашение «Кто учится?» с формой создания.

## Учебник: формат данных модуля

Каждый модуль = `data/textbook/u<NN>.js`, добавляющий в `window.TEXTBOOK`:

```js
window.TEXTBOOK = window.TEXTBOOK || {};
window.TEXTBOOK.u01 = {
  id: 'u01',
  number: 1,
  title: { es: 'el hijo, la hija', topic: 'Masculino, femenino (1)' },
  topicRu: 'Род существительных-людей',
  theory: [
    { type: 'rule', es: '...', ru: '...', examples: [{ es: 'el hijo', ru: 'сын' }] },
    { type: 'table', caption: '...', columns: [...], rows: [[...], ...], colClasses: [...] },
    { type: 'atencion', es: '...', ru: '...' },
    { type: 'heading', text: '...' },
  ],
  exercises: [
    {
      id: '1.1',
      title: '...',
      type: 'fill' | 'choice' | 'multi' | 'match',
      instructions: '...',     // HTML
      pool: [...],             // только для match: общий пул вариантов
      questions: [
        { id: 'q1', prompt: '<HTML>', correct: '<строка>' | ['вар1','вар2'], explanation: '?', audio: '?', placeholder: '?' },
        // для choice: options: [...], correct: '<value>'
        // для multi:  options: [...], correct: ['<value>',...]
      ],
    },
    ...
  ],
};
```

Принципы наполнения:

1. **Правила — академический пересказ** в духе `notes.html`: короткое
   определение на испанском (свои слова, не копия учебника-источника),
   пояснение на русском, 2–4 примера с переводом. Внимание/исключения —
   `type: 'atencion'`.
2. **Упражнений 10–15 на модуль.** Базовый набор: одно «развернуть форму»
   (fill), один «выбор артикля/варианта» (choice), один «поставьте все
   подходящие» (multi), одно сопоставление (match), одно с аудиодиктантом
   (fill + поле `audio`).
3. **Диакритика обязательна.** Сравнение строгое (см. `answerEqual` в
   `textbook.js`): `á é í ó ú ñ ü ¿ ¡` сравниваются буква в букву.
   Допустимы несколько правильных ответов через массив.

## Стиль перевода и копирайт

PDF в корне — **источник идей**, не материал для построчной перепечатки.
Правила формулируем своими словами, упражнения создаём оригинальные
(но в той же педагогической форме). Это и юридически чисто, и педагогически
лучше — потому что русские пояснения нацелены на конкретного ученика.

## Подключение нового модуля

1. Создать `app/data/textbook/u<NN>.js` по структуре выше.
2. Создать `app/textbook/u<NN>.html` копией `u01.html` с заменой
   `u01` → `u<NN>` в двух местах.
3. В `app/textbook.html` дописать `<script src="data/textbook/u<NN>.js"></script>`
   и добавить `'u<NN>'` в массив `ids`.

## Подключение нового глагола (тренажёр)

См. `app/PROMPT.md` — там готовый промпт с форматом `data/verbs/<inf>.js`.

## Работа с PDF-источником

PDF сканированный (без текстового слоя). Для чтения страниц рендерим в JPEG:

```bash
pdftoppm -r 110 -f <первая_страница> -l <последняя> -jpeg \
  "gramatica del uso del espanol.pdf" /tmp/gram_pages/p
```

Книжная страница 10 ≈ PDF-страница 16 (5 страниц обложки и индекса спереди).
Каждая Unidad = разворот: чётная страница теория, нечётная — упражнения.

## Известные ограничения

- IndexedDB не шарится между браузерами и устройствами — для переноса
  пользуйтесь экспортом JSON.
- SpeechSynthesis качество зависит от системного голоса. На macOS
  лучше всего звучит `Mónica` или `Jorge` — выбираются через системные
  настройки speech.
- Старый `app/spanish-trainer_6.html` — снимок до разделения на страницы;
  он самостоятелен и не использует общие скрипты.
