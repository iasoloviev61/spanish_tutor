# Добавление нового модуля учебника

Параллель к `PROMPT.md` (тот — для тренажёра глаголов). Готовый промпт для генерации
файла `app/data/textbook/u<NN>.js`. Структура модуля и принципы изложены в
`CLAUDE.md` (раздел «Учебник: формат данных модуля»).

---

## Промпт для Claude

> Сгенерируй данные для модуля учебника **Unidad `<NN>`** по теме
> **«`<ТЕМА>`»** (например: «Adjetivos calificativos» — прилагательные).
>
> Формат — один JS-файл, который добавляет объект в `window.TEXTBOOK`.
> Структура объекта — как в `app/data/textbook/u01.js` (это эталон):
>
> ```js
> window.TEXTBOOK = window.TEXTBOOK || {};
> window.TEXTBOOK['u<NN>'] = {
>   id: 'u<NN>',
>   number: <N>,
>   title: { es: '<заголовок-пример из темы>', topic: '<подзаголовок-тема>' },
>   topicRu: '<тема одной строкой по-русски>',
>   theory: [
>     { type: 'rule',     es: '<кратко на испанском, своими словами>',
>                          ru: '<развёрнутое объяснение по-русски>',
>                          examples: [{ es: '...', ru: '...' }, ...] },
>     { type: 'table',    caption: '...', columns: [...],
>                          colClasses: ['col-pattern','col-result','col-ex',...],
>                          rows: [['<HTML>', '<HTML>', '<HTML>'], ...] },
>     { type: 'atencion', es: '<кратко на исп>', ru: '<пояснение по-русски>' },
>     { type: 'heading',  text: '<подзаголовок раздела>' },
>   ],
>   exercises: [
>     {
>       id: '<N>.1',
>       title: '<краткий заголовок>',
>       type: 'fill' | 'choice' | 'multi' | 'match',
>       instructions: '<инструкция HTML>',
>       pool: ['...', '...'],   // только для match — общий список вариантов
>       questions: [
>         // fill:
>         { id: 'q1', prompt: '<HTML с <em></em>>', correct: '<строка>' | ['<вар1>','<вар2>'],
>            placeholder: '<опц.>', explanation: '<опц.>', audio: '<опц., текст для TTS>' },
>         // choice:
>         { id: 'q1', prompt: '...', options: ['a','b','c'], correct: 'a', explanation: '...' },
>         // multi:
>         { id: 'q1', prompt: '...', options: [...], correct: ['a','c','d'], explanation: '...' },
>         // match (singleton question или несколько; pool в самом упражнении):
>         { id: 'q1', prompt: '<слово слева>', correct: '<пара из pool>' },
>       ],
>     },
>     // ... 10–15 упражнений
>   ],
> };
> ```
>
> Требования:
>
> 1. **Правила своими словами.** Не цитируйте дословно никакие учебники.
>    Кратко на испанском (1–3 предложения), затем развёрнуто на русском.
>    Грамматические факты — нейтральные, языковые.
> 2. **Тон и стиль** как в `notes.html`: академический, лаконичный,
>    с курсивом для испанских форм через `<em>...</em>` и желтоватой
>    подсветкой ключевых слов через `<strong>...</strong>`.
> 3. **10–15 упражнений** с типами разной сложности.
>    Минимальный набор: один `fill` на образование форм, один `choice` на
>    выбор формы, один `multi` на классификацию, один `match` на сопоставление,
>    один `fill` с полем `audio` (диктант). Остальные — на ваше усмотрение,
>    но всегда с возрастающей сложностью.
> 4. **Диакритика обязательна** во всех правильных ответах: `á é í ó ú ñ ü ¿ ¡`.
>    Сравнение строгое — буква в букву, без учёта регистра и финальной пунктуации.
> 5. **Если правильных ответов несколько** — передайте массив строк в `correct`.
>    Например, для перифраз с пунктуацией: `correct: ['Es médico.', 'Es médico']`.
> 6. **Объяснения** в `explanation` — короткие, на русском, поясняют,
>    почему этот ответ правильный (или какое правило применилось).
> 7. **Лексика** — типичная для уровня A1–A2: семья, профессии, еда,
>    дом, числа, время. Избегайте редких слов.
> 8. **Никаких внешних ресурсов**: HTML только инлайновый, никаких `<img>`,
>    `<iframe>`, ссылок на CDN. Всё, что нужно — `<em>`, `<strong>`, `<code>`,
>    `<br>`.
> 9. **Никаких пояснений до или после кода.** Только готовое содержимое
>    файла, начиная с `// Unidad <NN>` и заканчивая `};`.

## После генерации

1. Сохрани файл как `app/data/textbook/u<NN>.js`.
2. Создай `app/textbook/u<NN>.html` — копия `u01.html` с заменой
   `u01` → `u<NN>` (3 места: `<title>`, `<subtitle>`, имя файла данных
   и аргумент `mountUnitPage`).
3. В `app/textbook.html`:
   - добавь `<script src="data/textbook/u<NN>.js"></script>` к остальным;
   - добавь `'u<NN>'` в массив `ids`.
4. Открой `textbook.html` в браузере, проверь:
   - модуль виден в списке;
   - страница модуля открывается, теория отображается, упражнения проходятся;
   - после клика «Проверить упражнение» подсвечиваются ошибки и сохраняется прогресс;
   - после возврата на хаб видно `N/Y` решённых вопросов в карточке.

## Эталон

`app/data/textbook/u01.js` — Unidad 1 «Masculino, femenino (1)». Все новые
модули должны соответствовать его структуре и стилю. `u02..u05.js` —
готовые примеры по другим темам (род вещей, plural, неопределённый артикль,
отсутствие артикля).
