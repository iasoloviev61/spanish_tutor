# Добавление нового глагола

Этот файл — готовый промпт для Claude. Скопируй блок ниже, замени `<INFINITIVE>` и `<ПЕРЕВОД>` и отправь в Claude. На выходе получишь содержимое файла `data/verbs/<infinitive>.js`, который нужно положить в `app/data/verbs/` и подключить в `app/index.html` строкой:

```html
<script src="data/verbs/<infinitive>.js"></script>
```

(добавь её к остальным `<script src="data/verbs/...">` перед строкой `<script src="js/trainer.js"></script>`).

## Промпт для Claude

> Сгенерируй данные для глагола **`<INFINITIVE>`** («`<ПЕРЕВОД>`») для тренажёра испанских глаголов.
>
> Формат — один JS-файл, который добавляет объект в `window.VERBS`. Структура объекта:
>
> ```js
> // Глагол «<INFINITIVE>» — <ПЕРЕВОД>
> window.VERBS.push({
>   "infinitive": "<INFINITIVE>",
>   "translation": "<ПЕРЕВОД>",
>   "group": "ar" | "er" | "ir",          // окончание инфинитива
>   "irregular": true | false,             // true для неправильных
>   "frequent": true,                      // оставь true
>   "sentences": [
>     // ровно 36 примеров: 6 лиц × 3 времени × 2 варианта
>     // лица: yo, tu, el, nosotros, vosotros, ellos
>     // времена: presente, indefinido, futuro
>     {
>       "person": "yo",
>       "tense": "presente",
>       "es": "Yo <форма> ...",
>       "ru": "Я ..."
>     },
>     {
>       "person": "yo",
>       "tense": "presente",
>       "es": "Yo <форма> ...",
>       "ru": "Я ...",
>       "variant": 2
>     }
>     // ... и так далее по всем 6 лицам × 3 временам × 2 вариантам
>   ],
>   "forms": {
>     "presente":   { "yo": "...", "tu": "...", "el": "...", "nosotros": "...", "vosotros": "...", "ellos": "..." },
>     "indefinido": { "yo": "...", "tu": "...", "el": "...", "nosotros": "...", "vosotros": "...", "ellos": "..." },
>     "futuro":     { "yo": "...", "tu": "...", "el": "...", "nosotros": "...", "vosotros": "...", "ellos": "..." }
>   }
> });
> ```
>
> Требования:
>
> 1. **Ровно 36 фраз** в `sentences`: каждая комбинация лица и времени встречается дважды (вариант 1 без поля, вариант 2 с `"variant": 2`).
> 2. **Простые, бытовые фразы** (3–6 слов), как в учебнике для начинающих. Подлежащее **обязательно явное** (Yo, Tú, Él/Ella, Nosotros, Vosotros, Ellos/Ellas) — потому что тренажёр учит спряжения.
> 3. **Перевод на русский** — естественный, не дословный. Учитывай вид (несов./сов.): для `presente` — несовершенный («говорю»), для `indefinido` — чаще совершенный («поговорил»), для `futuro` — будущее («поговорю/буду говорить»).
> 4. **Диакритика обязательна**: ударения (á é í ó ú), ñ, ¿ ¡. Тренажёр сравнивает строго.
> 5. **`forms`** — полная таблица спряжения по 6 лицам × 3 временам, **без подлежащих**, только формы глагола (например, `"hablo"`, не `"yo hablo"`).
> 6. **Не пиши никаких пояснений** до или после кода. Только готовое содержимое файла.
>
> Выведи весь файл целиком, начиная с комментария `// Глагол ...` и заканчивая `});`.
